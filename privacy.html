PDA privacy policy

Last updated: November 6, 2026

PDA is a personal Windows app used only by its owner. This page explains what it does with Google account data.

What PDA accesses

With the owner's permission, PDA uses the Gmail API to read the newest messages in the owner's inbox (sender, subject, a short preview and the date) and to mark messages read or unread or archive them when the owner asks it to. PDA does not send email and does not permanently delete email.

Where the data goes

Everything stays on the owner's own computer. Message details are kept in a local database, and sign-in tokens are kept in Windows Credential Manager. PDA has no server. It does not sell, share or transfer Google user data to anyone, and does not use it for advertising.

Optional AI summaries

If the owner turns on email summaries, a message's text may be sent to the Anthropic Claude API to make a one-line summary for the owner. This only happens for the owner's own mail, at the owner's choice, and the summary is shown only to the owner.

Google API Services User Data Policy

PDA's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time from PDA's settings (Disconnect) or at myaccount.google.com/permissions. Disconnecting deletes the stored messages and sign-in from the computer.
